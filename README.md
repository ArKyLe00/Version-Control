# Flask To-Do App

A Flask and MongoDB web application built to demonstrate full-stack development and Git version control workflows (branching, merging, conflict resolution, and rebasing).

## 🚀 Features
- **To-Do Form:** Frontend interface collecting `itemName`, `itemDescription`, `itemID`, `itemUUID`, and `itemHash`.
- **API Endpoint:** `/submittodoitem` POST route saving submissions to MongoDB.
- **Git History:** Multi-branch workflow showcasing soft resets and rebasing.

## 🛠️ Project Branches
- `main`: Core production codebase.
- `master_1`: Frontend templates and form fields.
- `master_2`: Backend Flask routes and MongoDB logic.
- `anirban_new`: API JSON configuration update.
